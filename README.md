# Notes API

Учебный REST API для заметок на FastAPI. Хранение данных в памяти (после перезапуска сервера заметки сбрасываются).

## Установка

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Из корня репозитория:

```
uvicorn notes_api.main:app --reload
```

Сервер: `http://127.0.0.1:8000`. Интерактивная документация: `http://127.0.0.1:8000/docs`.

## Модель заметки

| Поле  | Тип | Ограничения             |
|-------|-----|-------------------------|
| id    | int | больше 0                |
| title | str | от 1 до 100 символов    |
| text  | str | до 1000 символов, по умолчанию пустая строка |

## Эндпоинты

| Метод  | Путь               | Описание                  | Статусы              |
|--------|--------------------|---------------------------|----------------------|
| GET    | `/notes`           | Список всех заметок       | 200                  |
| GET    | `/notes/{note_id}` | Одна заметка              | 200, 404             |
| POST   | `/notes`           | Создать заметку           | 201, 409, 422        |
| PUT    | `/notes/{note_id}` | Заменить заметку          | 200, 400, 404, 422   |
| DELETE | `/notes/{note_id}` | Удалить заметку           | 204, 404             |

Расшифровка ошибок:
- 400: `id` в теле не совпадает с `id` в пути
- 404: заметка не найдена
- 409: заметка с таким `id` уже существует
- 422: данные не прошли валидацию
